# Piloto-de-Mecha
Este projeto se trata de Gerenciamento de Robô de combate (Mecha), onde o piloto (usuário) deve balancear o uso de energia entre os escudos e armas do robô, enquanto se preocupa com o aquecimento do núcleo.
Arena Core - Gerenciamento de Robô de Combate
Como Executar o Projeto

### Pré-requisitos
* **JDK 17** ou superior instalado.
* **Kotlin Compiler (`kotlinc`)** instalado (ou utilize uma IDE como IntelliJ IDEA / Android Studio).
